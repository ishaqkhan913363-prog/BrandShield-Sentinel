What happens during import?

Each row is validated and scored using the local heuristic engine. Official identifiers, duplicates and invalid rows are skipped and counted in the import summary. Imported records are saved in SQLite and can be investigated individually.

Required columns and optional signals

nameRequired · profile or listing name

developerOptional · app publisher
descriptionOptional · observed description
logo_matchOptional · 1 / true / yes if manually similar
